# Forma — сайт онлайн-курсов

Учебный проект по ТЗ: фронтенд на **React + Vite + CSS**, без бэкенда, UI-библиотек и CSS-фреймворков.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`.

## Страницы

- `/` — Landing: меню с мобильным бургером, Hero, шесть курсов, футер.
- `/register` — регистрация: имя, email, пароль (от 8 символов), подтверждение; ошибки под полями.
- `/login` — вход с проверкой по моковым данным.

После регистрации данные сохраняются **локально в localStorage только для демонстрации**, затем открывается страница входа. Тестовый аккаунт: `demo@forma.kz` / `password123`. **Это не безопасная реализация авторизации и не предназначено для продакшена.**

## Дизайн

Mobile-first: базовые стили под 360px; медиазапросы от 768px и 1200px. Светлая палитра, один шрифт DM Sans, карточки с CSS-иллюстрациями вместо внешних изображений.
